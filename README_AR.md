# جدول دروسي — Android

تطبيق عربي لإدارة مواعيد الدروس، الطلاب، الحضور والغياب والحسابات.

## المتطلبات للبناء
- Android Studio حديث
- Android SDK Platform 35
- JDK 17 أو أحدث
- اتصال إنترنت أول مرة لتنزيل Gradle/Android Gradle Plugin إذا لم تكن مخزنة محليًا.

## إخراج APK
افتح المجلد في Android Studio ثم اختر:
Build → Build Bundle(s) / APK(s) → Build APK(s)

ملف APK الناتج يكون داخل:
`app/build/outputs/apk/debug/`
